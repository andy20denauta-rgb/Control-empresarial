# Control Empresarial

PWA móvil-first para inversiones, inventario, ventas, recuperación de capital, utilidades y gastos.

## Regla contable
Costo puesto = costo de mercancía + envío prorrateado. Al vender, ese costo recupera capital; la diferencia entre venta y costo puesto es ganancia bruta.

## Publicar
Sube el contenido de esta carpeta a la raíz de `Control-empresarial`. Luego activa GitHub Pages desde Settings > Pages, usando `main` y `/ (root)`.

Los datos se guardan localmente en el dispositivo. Usa Exportar JSON para respaldarlos.
